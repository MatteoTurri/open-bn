
VU0行列演算ライブラリ
======================


 1 ライブラリ概要
------------------

    libvu0は、VU0マクロ命令を用いてベクトル演算・マトリックス演算を行うラ
    イブラリです。
    floatの4次元ベクトルを扱う関数として、加減算、スカラー乗除算、正規化、
    内挿、外積、内積、また複写や固定小数4次元ベクトルとの相互変換などが用
    意されています。また、floatの４×４行列を扱う関数として、積、ベクトル
    積、転置行列、逆行列、平行移動、回転などの一般的な行列演算に加えて、
    クリッピング、透視変換、また、ワールドビュー行列／ノーマルライト行列
    ／ライトカラー行列／スクリーンビュー行列／ドロップシャドウ行列を得る
    など、3Dグラフィクス処理に特有の処理が用意されています。
    このほか、VU0 / VIF0を初期化する関数があります。

  1.1 引数のハンドリング

    libvu0の各関数は、引数の個数や型はそれぞれ処理内容に応じて異なります
    が、関数の型はvoidで演算結果は第１引数（ベクトルまたはマトリックス）
    に返すように、一部の例外を除いてほぼ統一されています。
    VU0は基本的に128bit（float×4）を単位として演算を行いますので、各関数
    の引数も基本的に128bit単位となっています。引数のベクトルやマトリック
    スは128bitアライメントに合せた状態にして呼び出す必要があります。

  1.2 各関数が使用するレジスタ

    libvu0（Release 1.2以降）の各関数がVU0のVFレジスタのうちどれを使用す
    るか、以下にまとめて示します。次の表で○印のレジスタは、該当する関数
    を呼び出すことによって内容が破壊されますので、必要ならば呼び出しプロ
    グラム側で退避してください。−印のレジスタは使用されないので、退避の
    必要はありません。

 1 構造体
==========

=========================================================================
ps2_vu0_fmatrix                                                  [構造体]
=========================================================================
                                                          4x4マトリックス
[構造]
        typedef ps2_vu0_fvector ps2_vu0_fmatrix[4];
        
[解説]
        float×4×4要素のマトリックスです。行列要素としての並びは次のよう
        になっています。
        
        |m[0][0] m[1][0] m[2][0] m[3][0]|
        |m[0][1] m[1][1] m[2][1] m[3][1]|
        |m[0][2] m[1][2] m[2][2] m[3][2]|
        |m[0][3] m[1][3] m[2][3] m[3][3]|
        
=========================================================================
ps2_vu0_fvector                                                  [構造体]
=========================================================================
                                                4次元ベクトル（浮動小数）
[構造]
        typedef float ps2_vu0_fvector[4];
        
[解説]
        float×4要素のベクトルです。EEはリトルエンディアンであり、ps2_vu0_f
        vectorの配列要素とベクトル要素(フィールド)との対応は次のようにな
        っています。
        
        +--------+----------+
        |配列要素 フィールド|
        +--------+----------+
        |a[0]     x         |
        |a[1]     y         |
        |a[2]     z         |
        |a[3]     w         |
        +--------+----------+
        
=========================================================================
ps2_vu0_ivector                                                  [構造体]
=========================================================================
                                                    4次元ベクトル（整数）
[構造]
        typedef int ps2_vu0_ivector[4];
        
[解説]
        int×4要素のベクトルです。EEはリトルエンディアンであり、ps2_vu0_ive
        ctorの配列要素とベクトル要素(フィールド)との対応は次のようになっ
        ています。
        
        +--------+----------+
        |配列要素 フィールド|
        +--------+----------+
        |a[0]     x         |
        |a[1]     y         |
        |a[2]     z         |
        |a[3]     w         |
        +--------+----------+
        
        ps2_vu0_ivectorは、小数部0bitの固定小数点数または小数部4bitの固定小
        数点数と、ふたつの数値フォーマットで使用することができます。
        
        +----------------+------------------------+
        |フォーマット     仕様                    |
        +----------------+------------------------+
        |固定小数点(32.0) 整数部:32bit,小数部:0bit|
        |固定小数点(28.4) 整数部:24bit,小数部:4bit|
        +----------------+------------------------+

=========================================================================
ps2_vu0_add_vector                                                 [関数]
=========================================================================
                                                     4並列加算 (ADD/xyzw)
[形式]
        void ps2_vu0_add_vector(
        	ps2_vu0_fvector v0,
        	ps2_vu0_fvector v1,
        	ps2_vu0_fvector v2
        )
        
[引数]
        v0	出力:ベクトル
        v1,v2	入力:ベクトル
        
[返り値]
        なし
        
[解説]
        ベクトルv1の各要素とベクトルv2の各要素を各々加算し、結果をv0に返
        します。
        
=========================================================================
ps2_vu0_apply_matrix                                               [関数]
=========================================================================
                                             ベクトルとマトリックスの乗算
[形式]
        void ps2_vu0_apply_matrix(
        	ps2_vu0_fvector v0,
        	ps2_vu0_fmatrix m0,
        	ps2_vu0_fvector v1
        )
        
[引数]
        v0		出力:ベクトル
        m0		入力:マトリックス
        v1		入力:ベクトル
        
[返り値]
        なし
        
[解説]
        マトリックスm0にベクトルv1を右から乗算し、結果をベクトルv0に返し
        ます。式で表現すると次のとおりです。
        v0=m0*v1

ps2_vu0_camera_matrix                                              [関数]
=========================================================================
                                                 ワールドビュー行列の生成
[形式]
        void ps2_vu0_camera_matrix(
        	ps2_vu0_fmatrix m,
        	ps2_vu0_fvector p,
        	ps2_vu0_fvector zd,
        	ps2_vu0_fvector yd
        );
        
[引数]
        m		出力:マトリックス(ビューワールド座標)
        p		入力:ベクトル(視点)
        zd		入力:ベクトル(視線)
        yd		入力:ベクトル(垂直方向)
        
[返り値]
        なし
        
[解説]
        視点pを(0,0,0)に、視線zdを(0,0,1)に、垂直方向ydを(0,1,0)にと変換
        するような行列を求め、mに返します。

ps2_vu0_clip_all                                                   [関数]
=========================================================================

[形式]
        int ps2_vu0_clip_all(
        	ps2_vu0_fvector minv,
        	ps2_vu0_fvector maxv,
        	ps2_vu0_fmatrix ms,
        	ps2_vu0_fvector *vm,
        	int n
        );

ps2_vu0_rot_trans_pers                                             [関数]
=========================================================================
                                                                 透視変換
[形式]
        void ps2_vu0_rot_trans_pers(
        	ps2_vu0_ivector v0,
        	ps2_vu0_fmatrix m0,
        	ps2_vu0_fvector v1,
        	int mode
        );
        
[引数]
        v0		出力:スクリーン座標を表すベクトル
        m0		入力:透視変換マトリックス
        v1		入力:頂点を表すベクトル
        mode		入力:出力座標値v0[2],v0[3]のフォーマット指定
        		0: 小数部4bitの固定小数点
        		1: 小数部0bitの固定小数点
        
[返り値]
        なし
        
[解説]
        ベクトルv1で与えられた頂点を、マトリックスm0によってスクリーン座
        標に透視変換し、ベクトルv0に返します。
        出力されるv0[0],v0[1]の数値フォーマットは小数部4bitの32bit符号付
        き固定小数点数です。v0[2],v0[3]の数値フォーマットはmodeの指定に応
        じて変わり、mode=0のときは小数部4bitの32bit符号なし固定小数点、mo
        de=1のときは小数部0bitの32bit符号なし固定小数点となります。GIFのP
        ACKEDモードでXYZF2,XYZF3を用いる場合には、mode=0を指定すると、PAC
        K時に整数部が切り出されるので有用です。
